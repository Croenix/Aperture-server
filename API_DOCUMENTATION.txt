================================================================================
2. HIERARCHICAL CATEGORY & METADATA SYSTEM OVERVIEW
================================================================================

1. MAIN CATEGORIES:
   - "image"      (Image Presets / LUTs / Lightroom Profiles)
   - "text"       (Text Presets / Captions / Quotes)
   - "font"       (Typography & Custom Fonts)
   - "sticker"    (Graphics, Badges & Icons)
   - "background" (Background Wallpapers & Backdrops)

2. SUB CATEGORIES:
   - Image Preset Defaults:
     "Vintage", "Modern", "Black & White", "Cinematic", "Portrait",
     "Landscape", "Moody", "Warm Tones", "Cool Tones", "Cyberpunk" + Custom
   - Text Preset Defaults:
     "Quotes", "Captions", "Lyrics" + Custom
   - Font Defaults:
     "Normal" + Custom
   - Sticker Defaults:
     "Badges", "Emoji", "Decorative", "Icons", "Anime", "Logos", "Vectors", "Labels", "Illustrations" + Custom
   - Background Defaults:
     "Abstract", "Nature", "Gradient", "Studio", "Textures", "Minimalist", "3D", "Urban", "Pattern" + Custom

3. PRICING & ACCESS TYPES:
   - "Free" (isPremium: false)
   - "Paid" / "Premium" (isPremium: true)

4. STICKER FORMATS:
   - "PNG" (Raster image format with transparency)
   - "SVG" (Scalable Vector Graphics format)

5. FONT LANGUAGES:
   - Default: "English" (Applied automatically for existing and new fonts if unspecified)
   - Pre-configured Options: "English", "Malayalam", "Tamil"
   - Custom Languages: Support for uploading or editing fonts in any custom language (e.g. "Hindi", "Arabic", "Kannada", "Telugu")

6. BACKGROUND ORIENTATIONS:
   - "portrait"  (Vertical aspect ratio for mobile screens / stories)
   - "landscape" (Horizontal aspect ratio for desktop / wide screens)

7. KEYWORDS & TAGS:
   - Up to 20 tags per image / background asset for search & indexing (e.g. ["vintage", "portrait", "neon", "cyber", "dark"])

4.1 UPLOAD PRESET / FILE
--------------------------------------------------------------------------------
Endpoint:
  POST https://aperture-server.onrender.com/api/v1/files

Headers:
  Authorization: Bearer aperture_upl_secret_key_2026
  Content-Type: multipart/form-data

Form-Data Parameters:
  - file (Required): Binary file (up to 100 MB)
  - title (Optional): Custom display title (e.g. "Amber Sunset")
  - mainCategory (Optional): "image", "text", "font", "sticker", or "background" (Default: "image")
  - subCategory (Optional): Subcategory name (e.g. "Vintage", "Quotes", "Normal", "Badges", "Abstract")
  - language (Optional): Font language (Default: "English", options: "English", "Malayalam", "Tamil", custom)
  - orientation (Optional): Background orientation ("portrait" or "landscape", Default: "portrait")
  - keywords (Optional): Comma-separated search keywords/tags for images & backgrounds (max 20 tags)
  - pricing (Optional): "Free" or "Paid" (Default: "Free")
  - isPremium (Optional): "true" or "false" (Default: "false")
  - format / stickerFormat (Optional): "PNG" or "SVG" (Applicable for stickers)

cURL Example:
  curl -X POST "https://aperture-server.onrender.com/api/v1/files" \
    -H "Authorization: Bearer aperture_upl_secret_key_2026" \
    -F "file=@/path/to/preset.dng" \
    -F "title=Amber Sunset" \
    -F "mainCategory=image" \
    -F "subCategory=Vintage" \
    -F "keywords=vintage, portrait, sunset" \

```javascript
async function getStickers(category = 'Badges', format = 'SVG') {

  const response = await fetch(url);

  console.log('Stickers:', data.stickers);

}

// 4. Fetch Backgrounds (Filter by orientation & keyword)
async function getBackgrounds(orientation = 'landscape', keyword = 'neon') {
  const url = `https://aperture-server.onrender.com/api/backgrounds?orientation=${orientation}&keyword=${encodeURIComponent(keyword)}`;
  const response = await fetch(url);
  const data = await response.json();
  console.log('Backgrounds:', data.backgrounds);
  return data.backgrounds;
}

// 5. Upload a File / Preset / Sticker / Font / Background
async function uploadFile(fileObject, title, mainCategory, subCategory, pricing, extraOptions = {}, apiKey) {
  const formData = new FormData();
  formData.append('file', fileObject);
  formData.append('title', title);
  formData.append('mainCategory', mainCategory); // 'image', 'text', 'font', 'sticker', 'background'
  formData.append('subCategory', subCategory);
  formData.append('pricing', pricing); // 'Free' or 'Paid'
  if (extraOptions.format) formData.append('format', extraOptions.format);
  if (extraOptions.language) formData.append('language', extraOptions.language);
  if (extraOptions.orientation) formData.append('orientation', extraOptions.orientation);
  if (extraOptions.keywords) formData.append('keywords', extraOptions.keywords);

  const response = await fetch('https://aperture-server.onrender.com/api/v1/files', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`
    },
    body: formData
  });

  return await response.json();
}
```

================================================================================
6. STANDARD ERROR FORMAT
================================================================================

All error responses follow this consistent JSON structure:

```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "A valid Bearer token must be provided via the Authorization header."
  }
}
```

Common Error Codes:
- `UNAUTHORIZED` (401): Missing or invalid Bearer token.
- `FORBIDDEN` (403): API key lacks the required permission scope.
- `NO_FILE_PROVIDED` (400): No file found in multipart upload.
- `FILE_NOT_FOUND` (404): Specified file ID was not found.
- `INVALID_FILE_ID` (400): Malformed file ID parameter.
- `FILE_TOO_LARGE` (413): File exceeded maximum allowed limit (100 MB).
- `RATE_LIMIT_EXCEEDED` (429): Exceeded rate limit (300 requests per 15 min).

7.1 UPLOAD FONT FILE
--------------------------------------------------------------------------------
Endpoint:
  POST /api/fonts or POST /api/v1/fonts

Headers:
  Authorization: Bearer <API_KEY> (Optional if unauthenticated upload is allowed)

Multipart Form-Data Fields:
