1. AUTHENTICATION & API KEYS
================================================================================

Pass the API Key in the HTTP Authorization header using the Bearer scheme:
  Authorization: Bearer <API_KEY>

Default Seed API Keys:
--------------------------------------------------------------------------------
Profile Name     Key Value                        Permissions
--------------------------------------------------------------------------------
Master Admin     aperture_adm_secret_key_2026     files:read, files:upload,
                                                  files:delete, files:manage
Uploader         aperture_upl_secret_key_2026     files:read, files:upload
Read-Only        aperture_ro_secret_key_2026      files:read
--------------------------------------------------------------------------------
* Public endpoints (GET /api/presets/*, /api/fonts/*, /api/stickers/*) and 
  direct downloads (/files/*) can be called with or without Authorization headers.


================================================================================
2. HIERARCHICAL CATEGORY & METADATA SYSTEM OVERVIEW
================================================================================

1. MAIN CATEGORIES:
   - "image"   (Image Presets / LUTs / Lightroom Profiles)
   - "text"    (Text Presets / Captions / Quotes)
   - "font"    (Typography & Custom Fonts)
   - "sticker" (Graphics, Badges & Icons)

2. SUB CATEGORIES:
   - Image Preset Defaults:
     "Vintage", "Modern", "Black & White", "Cinematic", "Portrait",
     "Landscape", "Moody", "Warm Tones", "Cool Tones", "Cyberpunk" + Custom
   - Text Preset Defaults:
     "Quotes", "Captions", "Lyrics" + Custom
   - Font Defaults:
     "Normal" + Custom
   - Sticker Defaults:
     "Badges", "Emoji", "Decorative", "Icons", "Anime", "Logos", "Vectors", "Labels", "Illustrations" + Custom

3. PRICING & ACCESS TYPES:
   - "Free" (isPremium: false)
   - "Paid" / "Premium" (isPremium: true)

4. STICKER FORMATS:
   - "PNG" (Raster image format with transparency)
   - "SVG" (Scalable Vector Graphics format)

Headers:
  Authorization: Bearer aperture_upl_secret_key_2026
  Content-Type: multipart/form-data

Form-Data Parameters:
  - file (Required): Binary file (up to 100 MB)
  - title (Optional): Custom display title (e.g. "Amber Sunset")
  - mainCategory (Optional): "image", "text", "font", or "sticker" (Default: "image")

  - isPremium (Optional): "true" or "false" (Default: "false")

5.1 JAVASCRIPT / TYPESCRIPT (FETCH)

```javascript
// 1. Fetch Image Presets
async function getImagePresets(subCategory = '') {
  const url = subCategory 
    ? `https://aperture-server.onrender.com/api/presets/image/${encodeURIComponent(subCategory)}`
    : 'https://aperture-server.onrender.com/api/presets/image';
  
  const response = await fetch(url);
  const data = await response.json();
  console.log('Image Presets:', data.presets);
  return data.presets;
}

// 2. Fetch Fonts
async function getFonts(subCategory = 'Normal') {
  const url = `https://aperture-server.onrender.com/api/fonts/${encodeURIComponent(subCategory)}`;
  const response = await fetch(url);
  const data = await response.json();
  console.log('Fonts:', data.fonts);
  return data.fonts;
}

// 3. Fetch Stickers (Filter by category & format)
async function getStickers(category = 'Badges', format = 'SVG') {
  const url = `https://aperture-server.onrender.com/api/stickers?category=${encodeURIComponent(category)}&format=${format}`;
  const response = await fetch(url);
  const data = await response.json();
  console.log('Stickers:', data.stickers);
  return data.stickers;
}

// 4. Upload a File / Preset / Sticker / Font
async function uploadFile(fileObject, title, mainCategory, subCategory, pricing, format, apiKey) {
  const formData = new FormData();
  formData.append('file', fileObject);
  formData.append('title', title);
  formData.append('mainCategory', mainCategory); // 'image', 'text', 'font', or 'sticker'
  formData.append('subCategory', subCategory);
  formData.append('pricing', pricing); // 'Free' or 'Paid'
  if (format) {
    formData.append('format', format); // 'PNG' or 'SVG' (For stickers)
  }

  const response = await fetch('https://aperture-server.onrender.com/api/v1/files', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`
    },
    body: formData
  });

  return await response.json();
}
```

6. STANDARD ERROR FORMAT
================================================================================

All error responses follow this consistent JSON structure:

```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "A valid Bearer token must be provided via the Authorization header."
  }
}
```

Common Error Codes:
- `UNAUTHORIZED` (401): Missing or invalid Bearer token.
- `FORBIDDEN` (403): API key lacks the required permission scope.
- `NO_FILE_PROVIDED` (400): No file found in multipart upload.
- `FILE_NOT_FOUND` (404): Specified file ID was not found.
- `INVALID_FILE_ID` (400): Malformed file ID parameter.
- `FILE_TOO_LARGE` (413): File exceeded maximum allowed limit (100 MB).
- `RATE_LIMIT_EXCEEDED` (429): Exceeded rate limit (300 requests per 15 min).

7.1 UPLOAD FONT FILE
--------------------------------------------------------------------------------
Endpoint:
  POST /api/fonts or POST /api/v1/fonts

Headers:
  Authorization: Bearer <API_KEY> (Optional if unauthenticated upload is allowed)

Multipart Form-Data Fields:
  - file (or fontFile): Font binary file (.ttf, .otf, .woff, .woff2, .eot)
  - name (or fontName / title): Display Name of the Font (e.g. "Roboto Bold", "Montserrat ExtraBold")
  - category (or subCategory / fontType): Font subcategory (Default: "Normal")
  - pricing (or isPremium): Access type ("Free" or "Paid")

cURL Example:
  curl -X POST "https://aperture-server.onrender.com/api/fonts" \
    -H "Authorization: Bearer aperture_upl_secret_key_2026" \
