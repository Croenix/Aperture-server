REST API Quick Reference & cURL Examples

1. Get Image Presets Only

curl -X GET http://localhost:3000/api/presets/image # Or filter by subcategory: curl -X GET http://localhost:3000/api/presets/image/Vintage

2. Get Text Presets Only

curl -X GET http://localhost:3000/api/presets/text # Or filter by subcategory: curl -X GET http://localhost:3000/api/presets/text/Quotes

3. Get All Categories & Subcategories Tree

curl -X GET http://localhost:3000/api/presets/categories

4. Upload Preset (with Main Category & Sub Category)

curl -X POST http://localhost:3000/api/v1/files \ -H "Authorization: Bearer aperture_upl_secret_key_2026" \ -F "file=@/path/to/preset.dng" \ -F "title=Amber Sunset" \ -F "mainCategory=image" \ -F "subCategory=Vintage"

5. Edit Preset Title & Category Hierarchy

curl -X PATCH http://localhost:3000/api/presets/f_8a72c91e4f2b \ -H "Content-Type: application/json" \ -d '{"title": "Updated Title", "mainCategory": "image", "subCategory": "Cinematic"}'

6. Download / Direct File Access

curl -O -J http://localhost:3000/files/f_8a72c91e4f2b/download
