REST API Quick Reference & cURL Examples

Presets API

1. Get Image Presets Only

curl -X GET http://localhost:3000/api/presets/image
# Or filter by subcategory:
curl -X GET http://localhost:3000/api/presets/image/Vintage
Presets API

2. Get Text Presets Only

curl -X GET http://localhost:3000/api/presets/text
# Or filter by subcategory:
curl -X GET http://localhost:3000/api/presets/text/Quotes
Category Tree

3. Get All Categories & Subcategories Tree

curl -X GET http://localhost:3000/api/presets/categories
Upload API

4. Upload Preset (with Main Category & Sub Category)

curl -X POST http://localhost:3000/api/v1/files \
  -H "Authorization: Bearer aperture_upl_secret_key_2026" \
  -F "file=@/path/to/preset.dng" \
  -F "title=Amber Sunset" \
  -F "mainCategory=image" \
  -F "subCategory=Vintage"
Edit API

5. Edit Preset Title & Category Hierarchy

curl -X PATCH http://localhost:3000/api/presets/f_8a72c91e4f2b \
  -H "Content-Type: application/json" \
  -d '{"title": "Updated Title", "mainCategory": "image", "subCategory": "Cinematic"}'
Font API

6. Font API - Upload & Get Fonts

curl -X POST http://localhost:3000/api/fonts \
  -H "Authorization: Bearer aperture_upl_secret_key_2026" \
  -F "file=@/path/to/font.ttf" \
  -F "name=Roboto Bold" \
  -F "subCategory=Free"

curl -X GET http://localhost:3000/api/fonts
Sticker API

7. Sticker API - Upload & Get Stickers

curl -X POST http://localhost:3000/api/stickers \
  -H "Authorization: Bearer aperture_upl_secret_key_2026" \
  -F "file=@/path/to/sticker.svg" \
  -F "name=Golden Star Badge" \
  -F "category=Badges"

curl -X GET http://localhost:3000/api/stickers
Streaming

8. Download / Direct File Stream Access

curl -O -J http://localhost:3000/files/f_8a72c91e4f2b/download
